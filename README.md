# vCare AMP interactive demo

[Open the demo page](https://happyducke.github.io/vCare-AMP-Workflow-Demo/)

Interactive prototype for Pack Jobs, PC barcode scanning, equivalent parts, Ready Inventory and Controller-based shipments. Illustrative data saves in each viewer's browser. Start with New Pack Job and Quick Scanner Demo Kit for a three-scan walkthrough.

This repository publishes the demo page only.
